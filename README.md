# Matplotlib Rust Wrapper
It contains two matplotlibs API: `plt.plot` and `fig, axes = plt.subplots`


## Functions supported:
- `plot`:
- `scatter`:
- `hist`:
- `imshow`:
- `fillbetween`
- `bar`
- `axhline`
- `axvline`
- `text`

- `suptitle`
- `set_axis`
- `grid`
- `set_xlim`
- `set_ylim`
- `set_xlabel`
- `set_ylabel`
- `set_title`
- `legend`
- `set_xticks`
- `set_yticks`
- `set_xtickslabels`
- `set_ytickslabels`
- `sharex`
- `sharey`

- `savefig`
- `tight_layout`
